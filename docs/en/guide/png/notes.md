::: warning STATUS & AVAILABILITY

- PNG is currently **unreleased**. The `picguin/png` package is not yet available.

- PNG is currently **pre-v1.0.0**, and the public API is expected to change between releases.

  Not all features defined in [the PNG 3.0 specification](https://www.w3.org/TR/png-3/) are currently supported,  
  and certain PNG data may fail or partially fail to decode.  
  <span class="subtext">(for more information, see [PNG: Decoding, Compatibility](./decoding#compatibility))</span>

:::
