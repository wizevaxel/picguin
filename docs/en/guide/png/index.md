# PNG: Overview

<!--@include: ./notes.md -->

### Notes

The implementation of this codec is based on the [PNG 3.0 specification](https://www.w3.org/TR/png-3/).

## Installation

PNG can be installed as a package via [pesde](https://docs.pesde.dev/) with `pesde add picguin/png`.  
Alternatively, you can download a `.rbxm` from [Releases](https://github.com/wizevaxel/picguin/releases?q=png%40).
<span class="subtext">(Latest: [**v0.1.1**](https://github.com/wizevaxel/picguin/releases/png@v0.1.1))</span>

See [Introduction, **Installation**](../introduction#installation) for a detailed installation guide.
